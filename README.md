# ChalleWeb (Challegram Web)

Неофициальная Web-версия клиента Telegram, написанная на Java Script.

# Как запустить на своем хостинге ?

1)Скачать архив с последней версией.

2)По пути *папка_с_файлами*/js/ найти файл app.js

3)Вставить свои API_ID и API_HASH (ищите @YOURAPIID@ и @YOURAPIHASH@ )

4)Сохранить и загрузить на хостинг

# Условия использования

Если вы хотите сделать копию Challegram Web, пожалуйста указывайте что ваш "форк" основан на Challegram.
